# Air Drawing 作品提交包

本目录按提交要求整理三类材料：

1. `01_说明文档/`：项目说明、技术说明、版权与第三方来源声明。
2. `02_项目内容/`：代码仓库、运行方式、功能验收和提交清单。
3. `03_展示内容/`：展示 PPT、现场演示脚本、答辩问答。

提交前请先填写 `00_待补信息.md` 中的项目名称、队员、指导教师、学校/单位、仓库地址和最终演示链接。材料中已经明确标注了真实实现与待补内容，不要把占位符原样提交。

## 建议提交顺序

1. 先填写待补信息并确认队员署名。
2. 将代码仓库设置为评委可访问的公开仓库，或给组委会提供私有仓库访问权限。
3. 按 `02_项目内容/提交清单.md` 检查 `.env`、API Key 和临时文件没有进入压缩包。
4. 使用 `npm start` 在演示电脑上启动项目，按 `03_展示内容/现场演示脚本.md` 录制或现场演示。
5. 提交 `Air-Drawing-项目展示.pptx`、说明文档和项目仓库链接。
