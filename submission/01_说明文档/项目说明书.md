# Air Drawing：实时手部追踪、隔空绘画与 3D 模型交互系统

## 1. 项目概述

Air Drawing 是一个运行在桌面浏览器中的实时空间交互工具。系统通过电脑摄像头识别手部关键点，将手指动作转换为画笔轨迹和 3D 模型操作，让使用者无需触摸屏幕即可绘画、观察人体器官模型和拆分查看独立部件。

系统面向课堂演示、人体结构观察、交互原型和创意表达。它提供真实摄像头识别，不使用模拟手势数据。

## 2. 解决的问题

- 鼠标绘画需要频繁操作设备，难以表达自然的空中轨迹。
- 3D 模型的鼠标移动、旋转和缩放需要在多个工具之间切换。
- 多个独立器官部件需要快速选择、移动、隐藏和拆分观察。
- 现场演示需要一个无需安装复杂桌面软件的浏览器工作台。

## 3. 核心功能

### 隔空绘画

- MediaPipe Hand Landmarker 实时识别一只或两只手的 21 个关键点。
- 摄像头画面显示手部骨架、关键点和食指坐标。
- 食指绘画模式：伸出食指落笔，弯曲或张掌停笔。
- 捏合绘画模式：拇指与食指捏合落笔，松开抬笔。
- One Euro 滤波、短暂漏检续接和快速移动插值，减少抖动和断点。
- 颜色、画笔粗细、橡皮擦、撤销、清空和一笔选择/移动。

### 3D 模型工作台

- 支持 OBJ、GLB 和整文件夹导入。
- 目录中的独立 OBJ 部件可以单独选择、隐藏、移动、旋转、缩放和拆分观察。
- V 字手势指向部件并停留约 0.55 秒完成选择。
- 单食指移动模型中心。
- 握拳旋转：左右绕屏幕 Y 轴，上下绕屏幕 X 轴。
- 拇指与食指捏合并上下移动控制等比缩放。
- 竖起拇指切换整体模型目标。
- 双手同时捏合可平移、缩放和绕屏幕 Z 轴滚转。
- 视口安全边界防止模型被手势拖出屏幕，缩放过大时自动限制比例。
- 支持复位目标、复位全部、保存状态和恢复保存。

### Hyper3D 模块

系统通过 Node 服务端代理 Hyper3D Rodin API。使用者输入文字或参考图，生成结果以 GLB 导入当前 3D 场景。API Key 只放在本地 `.env`，不发送到浏览器端。

## 4. 技术实现

| 模块 | 实现 |
|---|---|
| 页面 | HTML、CSS、原生 JavaScript |
| 手部识别 | Google MediaPipe Hand Landmarker |
| 绘画 | Canvas 2D，视频层与绘画层分离 |
| 3D | Three.js、OBJLoader、GLTFLoader、OrbitControls、TransformControls |
| 服务端 | Node.js 原生 HTTP 服务与 Hyper3D 代理 |
| 平滑 | One Euro 滤波、手势候选帧确认、捏合滞回 |
| 模型资源 | BodyParts3D 独立 OBJ 部件、用户导入 OBJ/GLB、Hyper3D GLB |

## 5. 安全和边界

- 摄像头数据只在浏览器本地处理，不上传到本项目服务端。
- Hyper3D 生成需要用户自己的 API Key 和账户额度。
- 相对深度 Z 用于距离变化提示，不等于摄像头到手的厘米距离。
- AI 生成或导入的人体模型用于交互原型和观察，不作为诊断、手术或医学结论依据。
- 现场演示必须准备无网络/无 API 的备用流程：使用本地 OBJ 模型完成手势演示。

- [ ] 摄像头允许后能看到手部骨架和关键点。
- [ ] 绘画能落笔、抬笔、撤销和清空。
- [ ] 3D 模型能加载，V 字能选择部件。
- [ ] 单指移动、握拳旋转、捏合缩放和双手模式均能演示。
