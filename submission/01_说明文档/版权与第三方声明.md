# 版权、来源与第三方工具声明

## 本项目原创部分

本项目的页面布局、交互流程、手势状态机、Canvas 绘画逻辑、3D 工作台逻辑、模型目录索引脚本、Node 服务端代理和项目文档由本项目团队编写。最终提交时请在 `00_待补信息.md` 填写真实团队成员和所属单位。

## 第三方工具和服务

| 名称 | 使用位置 | 来源/说明 |
|---|---|---|
| Google MediaPipe Hand Landmarker | `vendor/mp/`、`app.js` | Google MediaPipe Tasks Vision；用于手部 21 点识别。提交时保留官方许可证和模型文件说明。 |
| Three.js | `vendor/three/` | Three.js，代码文件包含 MIT 许可证标识；用于 WebGL 渲染、OBJ/GLB 加载和相机控制。 |
| Hyper3D Rodin API | `server.mjs` | 外部生成服务；按官方 API 文档和账户条款使用，生成会消耗账户额度。 |
| BodyParts3D | `partof_BP3D_4.0_obj_99/` | OBJ 文件头明确标注：BodyParts3D，(c) The Database Center for Life Science，CC Attribution-Share Alike 2.1 Japan。 |

## 资源和密钥处理

- `.env` 和 `RODIN_API_KEY` 不属于提交材料。
- 不提交摄像头录像、临时截图和个人路径信息。
- 若提交模型资源，保留其原始文件头、许可证和来源链接。
- Hyper3D 生成的模型应按 Hyper3D 服务条款和输出文件许可使用。
