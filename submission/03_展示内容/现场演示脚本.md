# 现场演示脚本（建议 6–7 分钟，符合 8 分钟建议上限）

## 演示前准备

1. 使用 Chrome 或 Edge，运行 `npm start`。
2. 提前允许摄像头权限，检查浏览器、WebGL、模型目录和电源。
3. 关闭通知和无关窗口，准备一个本地 OBJ 部件作为无网络备用。
4. 不在录屏或投影画面中展示 `.env`、API Key 和个人文件夹路径。

## 0:00–0:45 项目介绍

说明：Air Drawing 将摄像头手部关键点转换为空中笔迹和 3D 操作。绘画层与视频层分离，3D 模型可以按部件选择和观察。

## 0:45–2:15 隔空绘画

1. 点击“启动摄像头”。
2. 展示手部骨架、21 个关键点和食指坐标。
3. 伸出食指画一条线，弯曲食指停笔。
4. 快速移动，展示平滑和断点补线。
5. 切换颜色、粗细和橡皮擦，点击撤销和清空。

## 2:15–4:45 3D 部件操作

1. 进入“3D 解剖模型”，加载一个小部件或快速模块。
2. 启用 3D 手势。
3. 小拇指单独伸直进入锁定选择；伸出食指指向部件并停留约 0.4 秒完成选择。
4. 单食指移动部件。
5. 握拳左右移动，绕屏幕 Y 轴旋转；上下移动，绕屏幕 X 轴旋转。
6. 拇指与食指捏合，上下移动掌心缩放。
7. 张掌保持约 0.5 秒退出选择并进入安全中立；展示点击“复位目标”。

## 4:45–5:45 双手高级模式

1. 勾选双手高级模式。
2. 两只手同时捏合并保持约 0.2 秒。
3. 两手一起移动展示平移。
4. 拉开或靠拢两手展示缩放。
5. 改变两手连线角度展示绕屏幕 Z 轴滚转。
6. 松开一只手，展示立即停止。

## 5:45–6:30 模型来源和扩展

说明：本地 BodyParts3D 部件可逐件选择；OBJ/GLB 可以导入；Hyper3D 生成的 GLB 可以进入同一个场景。医学模型用于交互观察，不代替诊断或手术依据。

## 6:30–7:00 收尾

说明：系统支持本地浏览器运行，摄像头画面由浏览器本地处理，代码和资源来源列于提交材料。展示出现网络或 API 问题时，使用本地 OBJ 模型完成核心演示。

## 录屏要求

建议录制完整浏览器窗口或网页内容，分辨率至少 1920×1080；如需展示长页面，可分段滚动并剪辑为连续片段。成片控制在 8 分钟以内，保留清晰的手势画面、屏幕反馈和操作结果。录制前关闭通知并检查页面没有 API Key、个人路径或不应公开的摄像头背景。
