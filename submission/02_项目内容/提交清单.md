# 项目内容提交清单

## 代码仓库应包含

- `index.html`
- `styles.css`
- `app.js`
- `server.mjs`
- `package.json`
- `vendor/`
- `model-catalog.json`
- `partof_BP3D_4.0_obj_99/` 或评委可下载的模型资源包
- `README.md`
- `USER_GUIDE.md`
- `CONTRIBUTING.md`
- `.github/`
- `submission/` 中的项目说明、技术与第三方声明、演示脚本和答辩材料

## 代码仓库不应包含

- `.env`
- `RODIN_API_KEY`
- 摄像头录像
- 个人桌面截图和临时文件
- 未确认许可的模型、纹理或数据集

## 评委运行方式

```bash
npm run check
npm start
```

打开 `http://localhost:8000/`，允许摄像头权限。进入“3D 解剖模型”后，可以选择本地模型或快速模块。Hyper3D 不是基础演示的必需项，现场应优先使用本地模型完成演示。

## 交付包生成前检查

- [ ] `npm run check` 通过，演示电脑可执行 `npm start`。
- [ ] 公开仓库代码与参赛版本一致；若提交私有仓库，已为评委授权。
- [ ] 源码压缩包中没有 `.env`、API Key、`node_modules/`、录屏、个人截图或临时文件。
- [ ] 每个第三方库、字体、模型、数据集均注明来源与许可证，必要的 LICENSE / NOTICE 保留。
- [ ] BodyParts3D 资源分发方式符合其 CC BY-SA 2.1 Japan 要求及赛事规则。
- [ ] PPT、说明书和演示视频使用相同项目名称、功能版本和成员署名。
- [ ] MP4 不超过 8 分钟；视频从启动/功能演示到结果完整，画面可读且不暴露密钥或私人信息。
- [ ] 交付介质包含：说明文档、项目/代码仓库、技术与第三方说明、PPT、现场 Demo 或 MP4。
