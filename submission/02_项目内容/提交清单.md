# 项目内容提交清单

## 代码仓库应包含

- `index.html`
- `styles.css`
- `app.js`
- `server.mjs`
- `package.json`
- `vendor/`
- `model-catalog.json`
- `partof_BP3D_4.0_obj_99/` 或评委可下载的模型资源包
- `README.md`
- `USER_GUIDE.md`
- `CONTRIBUTING.md`
- `.github/`

## 代码仓库不应包含

- `.env`
- `RODIN_API_KEY`
- 摄像头录像
- 个人桌面截图和临时文件
- 未确认许可的模型、纹理或数据集

## 评委运行方式

```bash
npm run check
npm start
```

打开 `http://localhost:8000/`，允许摄像头权限。进入“3D 解剖模型”后，可以选择本地模型或快速模块。Hyper3D 不是基础演示的必需项，现场应优先使用本地模型完成演示。
