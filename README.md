# Air Drawing

一个使用 Google MediaPipe Hand Landmarker 的实时手部追踪与隔空绘画网页。

## 运行

浏览器的摄像头 API 需要安全上下文。现在推荐使用项目自带的 Node 本地服务（Node.js 18.18 或更新版本）：

```bash
npm start
```

然后打开 <http://localhost:8000>。首次点击“启动摄像头”时，在浏览器提示中允许摄像头权限。MediaPipe 模型和字体首次加载需要网络连接；Three.js 与 MediaPipe JavaScript/WASM 依赖已保存在 `vendor/` 目录。

Windows 也可以双击 `start-air-drawing.bat`。如果 8000 端口已被占用，可用 PowerShell 设置 `$env:PORT=8001; npm start`，再打开对应端口。纯静态服务器仍可运行绘画和本地模型，但 Hyper3D 生成需要 `server.mjs` 代理。

## 多人协作开发

项目使用 Git 分支和 Pull Request 协作。新成员先运行 `npm run check` 和 `npm start` 确认本地环境，再从默认分支创建 `feat/*`、`fix/*` 或 `docs/*` 分支。提交前再次运行 `npm run check`，并在 Pull Request 中写明复现步骤、验证浏览器和是否涉及摄像头或模型资源。详细规则见 [CONTRIBUTING.md](CONTRIBUTING.md)。

仓库只保存代码、文档和必要的轻量资源。`.env`、Hyper3D API Key、摄像头录像和临时输出不会进入 Git；大量 OBJ/GLB 资源应使用 Git LFS 或单独的资源发布包管理。

## Hyper3D Rodin 模块

Hyper3D 已作为 3D 工作区的小功能模块接入，使用官方 Rodin Gen‑2.5 API：文字生成或上传最多 5 张参考图，默认请求 Gen‑2.5 Medium、GLB、Raw 20k 几何。生成是异步任务，界面会显示排队/生成状态；完成后点击输出文件即可下载并直接导入当前 3D 场景。

具体配置和使用流程见 [USER_GUIDE.md](USER_GUIDE.md)。接口实现依据 Hyper3D 官方文档：[Rodin Gen‑2.5](https://docs.hyper3d.ai/en/api-specification/rodin-gen2-5)、[Check Status](https://docs.hyper3d.ai/en/api-specification/check-status)、[Download Results](https://docs.hyper3d.ai/en/api-specification/download-results)。

API Key 只能放在本地 Node 服务端。配置步骤：

```bash
copy .env.example .env
# 编辑 .env，将 RODIN_API_KEY 替换为 Hyper3D API Dashboard 中的密钥
npm start
```

页面进入“3D 解剖模型”后，在左侧 `Hyper3D · Rodin` 区域填写文字或选择图片，点击“生成 3D 模型”。没有配置 Key 时模块会保持禁用并显示配置提示；不会把 Key 发送到浏览器。生成会消耗 Hyper3D 账户额度，正式使用前请在 Dashboard 检查余额、套餐与并发限制。

## 使用

- 点击“启动摄像头”，等待模型加载并把一只手放入左侧画面。
- MediaPipe 最多同时识别两只手；摄像头画面上用青色标右手、粉色标左手。默认右手是交互主手，可在“多手识别”选择左手；只有主手能绘画或控制 3D，另一只手仅显示骨架。
- 两只手左右标签不完整或手腕距离过近时，程序会暂停交互并结束当前笔画，避免从一只手跳到另一只手造成串线；分开后会重新识别并恢复。
- 拇指与食指捏合时开始绘画，松开时抬笔。手部离开画面会自动结束当前笔画。
- “手指使用模式”可切换为“食指绘画”：只伸出食指并移动即可落笔，张开手掌或收回食指会抬笔；该模式对应示例视频中的使用方式。
- 右侧控制台可切换颜色、画笔粗细、橡皮擦、撤销和清空。
- “选择/移动”会暂停隔空落笔；点击一笔后拖动即可移动整笔，点空白处取消选择。当前按抬笔边界区分笔画，不会自动把多笔识别并合并成语义图形。
- “绘画已暂停”只会暂停输入，不会清除已有线条。
- 快速移动时，程序会对相邻指尖采样进行插值补线，减少摄像头帧率波动造成的断点；手指靠近画布边缘时有小范围容错。
- 快速移动时会按采样间隔动态补点；手部短暂漏检会保留最多约 420ms 的续接窗口并补齐采样间的轨迹。超过窗口、明显跨区域跳点或停笔后重新移动会自动断笔，避免连接不连续轨迹。
- 摄像头优先请求 1280×720、60 FPS；实际 FPS 取决于摄像头、浏览器和 GPU。MediaPipe 使用 GPU 优先、CPU 回退，并通过置信度阈值抑制误检。
- 工作区顶部的“相对距离 / Z”显示手部距离变化：`1.00x` 是参考位置，小于 1 表示手更近，大于 1 表示手更远，同时显示 MediaPipe 的相对 Z 值。首次检测到手时会自动采集 12 帧建立参考，也可以点击“校准距离”重新设定当前参考位置。
- 相对值基于掌部 5–17 关键点的三维跨度（画面 X/Y 像素与 MediaPipe 相对 Z），再经过平滑处理；Z 本身不是摄像头到手的厘米深度。摄像头角度、手掌姿态和遮挡仍会影响结果。需要绝对厘米精度时应使用双目、深度摄像头或 LiDAR。

## 文件

- `index.html`：页面结构和控件。
- `styles.css`：响应式深色科技风界面。
- `app.js`：摄像头、MediaPipe 推理、平滑指尖、手势状态机和 Canvas 绘画逻辑。
- `vendor/three/`：与 Three.js r170 匹配的 OBJ 加载器、OrbitControls 和 TransformControls。
- `model-catalog.json`：从 BodyParts3D OBJ 文件头生成的 1,258 条模型索引。

## 3D 解剖模型工作区

当前目录中的 `partof_BP3D_4.0_obj_99/partof_BP3D_4.0_obj_99` 包含 1,258 个独立 OBJ 部件。应用会读取 `model-catalog.json` 中由 OBJ 文件头生成的 FJ 编号、英文名称和毫米范围，只有选中的部件才会加载到浏览器，因此不会在启动时一次性读取约 200 MB 几何数据。BodyParts3D 这批文件没有 MTL/纹理文件，界面使用科技风单色材质显示。

点击工作区顶部的“3D 解剖模型”后，可以按英文名称或 FJ 编号搜索，选中一个或多个结果并点击“添加选中部件”。场景列表可选择、显示/隐藏和移除部件；“拆分观察”会把选中独立部件从中心移开，“重置视角”会按当前场景重新居中。鼠标左键旋转视角、滚轮缩放、右键平移。

初次使用可先在模型库上方的“快速选择模块”选择胰腺、双肾、消化系统精选、主动脉主干或双侧股骨。点击“添加到当前场景”保留现有部件，或点击“清空后加载”用所选模块替换场景；模块由目录中真实存在的 FJ 编号组成，并会自动聚焦。建议先加载单个胰腺熟悉控件：点击“启用 3D 手势”，再用 V 字手势悬停选部件、单食指移动、握拳旋转、拇指与食指捏合缩放、竖起拇指切换到整体。放松手指即停止。拆分仍需单独点击“拆分观察”。

点击“导入 OBJ / GLB”可以导入本地模型；导入文件夹时，浏览器先索引 OBJ 文件头，搜索后再按需加载，适合整套 BodyParts3D 资源。Hyper3D 输出的 GLB 可从生成结果直接导入。进入“3D 解剖模型”后，绘画专属的食指/捏合绘画控件会隐藏。

## 3D 手控操作建议

启用 3D 手势后，无需再点移/转/缩切换按钮：V 字手势指向并停留约 0.55 秒可选部件；单食指移动，握拳旋转，拇指与食指捏合并上下移动来缩放；竖起拇指将目标切换为整体模型，之后继续使用单指、握拳或捏合操作整个场景。V 字选部件会自动返回部件目标。放松手指可停止操作，手离开画面会暂停并在重新检测后从当前点重新开始。

默认灵敏度为 0.65×、平滑为 65%。轻微抖动时把平滑提高到 75–85%；移动太快时把灵敏度降到 0.45–0.60×，拖动迟缓再小幅提高。选中的部件会显示青色包围框。“复位目标”恢复当前部件或整体的导入时变换；“复位全部”还原所有部件。“保存状态 / 恢复保存”在当前浏览器中保存并恢复当前部件组合的变换、显隐和相机视角。鼠标部件列表选择、轨道操作和变换手柄仍可作为备用；启用手势时移/转/缩与对象切换控件会隐藏。

单个 OBJ/GLB 内部如果只有一个网格，软件只能整体变换；BodyParts3D 目录中的每个 OBJ 已经是独立部件，所以可逐件拆分观察。Hyper3D 生成的 GLB 如果只有一个场景节点，也会作为一个整体部件导入；要实现器官级拆分，需要在建模软件中先分离网格后再导出多个 GLB/OBJ。

## 发布 / 打包

交付时保留 `index.html`、`styles.css`、`app.js`、`server.mjs`、`package.json`、`vendor/`、`model-catalog.json` 和模型资源目录；不要把 `.env` 或 API Key 放进压缩包。Windows 用户可直接双击 `start-air-drawing.bat`，其他平台运行 `npm start`。发布前应在目标机器用 `node --check app.js`、`node --check server.mjs` 检查语法，并用 Chrome/Edge 验证摄像头权限、WebGL、Hyper3D 任务状态和 GLB 导入。

`model-catalog.json` 可在资源目录更新后用 Node.js 重新生成：

```bash
node scripts/build_model_catalog.mjs
```
