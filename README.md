# Air Drawing

一个使用 Google MediaPipe Hand Landmarker 的实时手部追踪与隔空绘画网页。

## 运行

浏览器的摄像头 API 需要安全上下文。现在推荐使用项目自带的 Node 本地服务（Node.js 18.18 或更新版本）：

```bash
npm start
```

然后打开 <http://localhost:8000>。首次点击“启动摄像头”时，在浏览器提示中允许摄像头权限。MediaPipe 模型和字体首次加载需要网络连接；Three.js 与 MediaPipe JavaScript/WASM 依赖已保存在 `vendor/` 目录。

Windows 也可以双击 `start-air-drawing.bat`。如果 8000 端口已被占用，可用 PowerShell 设置 `$env:PORT=8001; npm start`，macOS 可运行 `PORT=8001 npm start`，再打开对应端口。纯静态服务器仍可运行绘画和本地模型，但图像编辑、AI 提示词和 Hyper3D 生成需要 `server.mjs` 代理。

## 多人协作开发

项目使用 Git 分支和 Pull Request 协作。新成员先运行 `npm run check` 和 `npm start` 确认本地环境，再从默认分支创建 `feat/*`、`fix/*` 或 `docs/*` 分支。提交前再次运行 `npm run check`，并在 Pull Request 中写明复现步骤、验证浏览器和是否涉及摄像头或模型资源。详细规则见 [CONTRIBUTING.md](CONTRIBUTING.md)。

运行 `npm test` 可验证捏合书写、橡皮擦手势、工具切换和页面控件初始化。测试使用合成手部关节和虚拟 DOM，不需要摄像头，也不能替代真实摄像头体验。

仓库只保存代码、文档和必要的轻量资源。`.env`、API Key、摄像头录像和临时输出不会进入 Git；大量 OBJ/GLB 资源应使用 Git LFS 或单独的资源发布包管理。

## 画板选区、图像编辑与 3D

用主控手的拇指与中指捏合约 0.25 秒，直接进入截取模式，以食指尖当前位置作为矩形起点。保持拇指与中指捏合，移动食指尖框出区域；将拇指与中指明显分开约 0.1 秒，即按最后保持捏合的位置完成截取。也可点击画布底部“截取区域”：先松开拇指与中指，再捏合拖选、松开完成。已有有效矩形时可点击“完成截取”，也支持鼠标拖选。

短暂漏检不超过约 0.3 秒时保留未完成选区，重新识别后可继续；较长时间丢手则取消当前矩形。漏检本身不会自动截取。选区导出为独立 PNG，并打开素材面板；只截取画布内容，不包含摄像头、骨架或选区边框，不会覆盖原画板。进入选区模式时画笔与橡皮擦暂停，退出后松开拇指与食指再继续绘画。

素材面板只需在“修改要求”中描述想要的效果。手动输入、语音转写和润色都使用同一个文本框，润色后可以直接修改：

- **生成编辑图**：将当前图片与修改要求发送给火山方舟 Seedream，结果保留为新版本，并在同一预览区显示，可继续编辑或下载 PNG。
- **生成 3D**：编辑完成后显示，将选中的编辑版本带入 Rodin 面板；确认参考图后点击“生成 3D 模型”才提交三维任务。原始选区需先完成图像编辑，才能从此流程带入 3D。
- **历史版本 / 更多选项**：按需展开，切换原图和编辑版本、设置 3D 参考图优化、填写可选的模型描述或查看服务配置。

图像编辑与图片转 3D 使用两家独立服务；Hyper3D 官网的图像编辑页面不作为项目 API 调用。关闭素材面板后，可从画布底部“图片素材”或 Rodin 素材卡的“返回图片编辑”重新打开，继续使用原有选区和版本。素材历史仅在本次页面会话中保留原图与最近 7 次编辑；重新框选会替换当前素材及历史，刷新前或重新框选前请下载需要保存的版本。

首次配置时，在项目根目录复制 `.env.example` 为 `.env`（macOS：`cp .env.example .env`）；已有 `.env` 时只追加缺少的变量，不要覆盖原文件。配置后重启 `npm start`：

| 变量 | 用途 |
| --- | --- |
| `SEEDREAM_API_KEY` | 火山方舟 API Key，用于 Seedream 图像编辑及可选的 AI 提示词 |
| `SEEDREAM_MODEL` | 账号已开通的 Seedream 图片编辑模型 ID / 推理接入点 ID，以方舟控制台为准 |
| `IMAGE_PROMPT_MODEL` | 可选：已开通、支持图片输入的方舟视觉模型 ID；配置后启用“AI 润色” |
| `RODIN_API_KEY` | Hyper3D Rodin API Key，用于图片或文字生成 3D |

以上密钥只由本机 Node 服务读取，不发送到页面。“更多选项”中的配置状态仅说明本地变量是否齐全，不代表服务已经联网验证或模型权限可用。图像编辑、AI 提示词和 Rodin 任务分别可能产生 API 费用，网页会员权益不等于 API 免费额度。没有配置图片编辑密钥时，仍可框选、下载 PNG，并使用本地提示词模板；没有 `IMAGE_PROMPT_MODEL` 时，“简单润色”只根据文字意图与选项组织固定描述，不分析图片内容。配置视觉模型后，“AI 润色”会将选定图片和修改要求发送给该模型。

“语音输入”在连续约 3 秒没有检测到语音活动或新的转写结果时自动结束，也可点击按钮手动结束。它使用浏览器的语音识别能力，兼容性、联网要求与隐私行为由浏览器提供方决定，不能保证所有浏览器可用。不支持时可手动输入，或在 macOS 打开系统听写后对文本框输入。语音转写与润色结果均可修改，不会自动提交编辑任务。摄像头识别、语音与外部 API 需要在目标设备和实际账号中验证。

## Hyper3D Rodin 模块

Hyper3D 已作为 3D 工作区的小功能模块接入，使用官方 Rodin Gen‑2.5 API：文字生成或上传最多 5 张参考图，默认请求 Gen‑2.5 Medium、GLB、Raw 20k 几何。生成是异步任务，界面会显示排队/生成状态；完成后点击输出文件即可下载并直接导入当前 3D 场景。

具体配置和使用流程见 [USER_GUIDE.md](USER_GUIDE.md)。接口实现依据 Hyper3D 官方文档：[Rodin Gen‑2.5](https://docs.hyper3d.ai/en/api-specification/rodin-gen2-5)、[Check Status](https://docs.hyper3d.ai/en/api-specification/check-status)、[Download Results](https://docs.hyper3d.ai/en/api-specification/download-results)。

API Key 只能放在本地 Node 服务端。配置步骤：

以下复制命令仅用于尚无 `.env` 的首次配置；已有文件请直接追加或修改变量，保留现有密钥。

```bash
cp .env.example .env
# 编辑 .env，在 RODIN_API_KEY= 后填写 Hyper3D API Dashboard 中的密钥
npm start
```

Windows 命令提示符中将第一行改为 `copy .env.example .env`。

页面进入“3D 解剖模型”后，在左侧 `Hyper3D · Rodin` 区域填写文字或选择图片，点击“生成 3D 模型”。没有配置 Key 时模块会保持禁用并显示配置提示；不会把 Key 发送到浏览器。生成会消耗 Hyper3D 账户额度，正式使用前请在 Dashboard 检查余额、套餐与并发限制。

## 使用

- 点击“启动摄像头”，等待模型加载并把一只手放到摄像头前。
- MediaPipe 最多同时识别两只手；摄像头画面上用青色标右手、粉色标左手。默认右手是交互主手，可在“多手识别”选择左手；只有主手能绘画或控制 3D，另一只手仅显示骨架。
- 两只手左右标签不完整或手腕距离过近时，程序会暂停交互并结束当前笔画，避免从一只手跳到另一只手造成串线；分开后会重新识别并恢复。
- 拇指尖与食指尖捏合时落笔，分开时收笔；其他三指的姿态不限，食指也无需保持伸直。以食指尖为绘画位置，保留现有平滑与补线。捏合使用校正视频宽高比后的画面平面距离，归一化尺度为 `max(掌宽 5–17, 0.65 × 掌长 0–9)`：小于 0.25 开始书写，已落笔后小于 0.35 可继续，达到 0.35 当帧停笔。估算深度的波动不再直接打断接触。绘画与 3D 模型捏合缩放使用各自的手势状态。
- 食指尖在摄像头内部活动区的位置左右镜像映射到整张画布：横向 12%–88%、纵向 8%–60%，底部预留 40% 画面给手掌和手腕，减少画角落时出框漏检。超出活动区但仍能识别时，绘画位置夹紧在画布边缘；绘画骨架使用相同映射。3D 工作区保持原有全幅映射。
- 左侧控制台可切换颜色、画笔粗细、橡皮擦、撤销和清空。点击“实时工作区”标题旁的箭头按钮可收起或展开控制台，收起后画板会占用释放的宽度，已有线条会保留。
- 仅保留直径 36 px 的小橡皮擦：食指与中指伸直并拢、无名指与小指弯曲，拇指自然收拢。五指张开或并拢均不会触发手势擦除。姿势需稳定 80 毫秒才开始擦除；任何未通过姿势判定的帧立即暂停擦除，160 毫秒内恢复相同姿势可直接另起擦除段，不跨失效区间连擦。分开的 V 字不会触发擦除。画布上的空心圆显示实际擦除范围。手势橡皮擦结束后，重新捏合拇指与食指会自动回到画笔；也可点击“橡皮擦”后捏合擦除，此时大小跟随笔刷粗细。
- 小橡皮擦保持原规则：进入时 PIP ≥150°、DIP ≥140°，保持时 PIP ≥140°、DIP ≥130°；仍需满足相应的并拢及其余手指条件。
- 为排查断线，绘画工作区暂时默认显示“摄像头分析”栏：全幅镜像原始视频、独立的骨架开关、捏合投影距离比、五指实测角度、主控手标签、当前落笔状态、手势诊断和最近停笔原因。手势诊断保留空间捏合距离供比较，并显示橡皮擦的具体未通过条件；空间捏合距离不控制书写起停。书写时五指角度不限；橡皮擦姿势显示对应角度条件。录屏时请同时包含画布与分析栏；取消勾选“摄像头分析”即可恢复大画布，后台识别继续运行。
- “绘画已暂停”只会暂停输入，不会清除已有线条。
- 松开捏合、进入并指橡皮擦姿势、切换工作区、暂停绘画、漏检手部、无效关节数据和推理异常均结束当前画笔笔画，不跨丢失片段续线。松开后再次捏合另起一笔。实际响应受摄像头及识别采样帧率影响，捏合书写与橡皮擦规则仍需在真实摄像头画面中验证。
- 姿势持续有效时，程序保留指尖平滑，并对相邻采样进行插值补线。漏检手部或关节点无法计算时，当帧结束当前笔画；恢复识别并满足绘画条件后另起一笔。
- 单目摄像头的平面捏合判定无法区分画面中完全重合、实际前后分离的两指；收笔时让两指在画面上明显分开。橡皮擦优先用世界关节数据判断；其判定失败时会尝试画面平面数据，改善侧手和关节深度估算不稳定时的识别，严重遮挡或出框仍会暂停。
- 摄像头优先请求 1280×720、60 FPS；实际 FPS 取决于摄像头、浏览器和 GPU。MediaPipe 使用 GPU 优先、CPU 回退，并通过置信度阈值抑制误检。
- 工作区顶部的“相对距离 / Z”显示手部距离变化：`1.00x` 是参考位置，小于 1 表示手更近，大于 1 表示手更远，同时显示 MediaPipe 的相对 Z 值。首次检测到手时会自动采集 12 帧建立参考，也可以点击“校准距离”重新设定当前参考位置。
- 相对值基于掌部 5–17 关键点的三维跨度（画面 X/Y 像素与 MediaPipe 相对 Z），再经过平滑处理；Z 本身不是摄像头到手的厘米深度。摄像头角度、手掌姿态和遮挡仍会影响结果。需要绝对厘米精度时应使用双目、深度摄像头或 LiDAR。

## 文件

- `index.html`：页面结构和控件。
- `styles.css`：响应式深色科技风界面。
- `app.js`：摄像头、MediaPipe 推理、平滑指尖、手势状态机和 Canvas 绘画逻辑。
- `vendor/three/`：与 Three.js r170 匹配的 OBJ 加载器、OrbitControls 和 TransformControls。
- `model-catalog.json`：从 BodyParts3D OBJ 文件头生成的 1,258 条模型索引。

## 3D 解剖模型工作区

当前目录中的 `partof_BP3D_4.0_obj_99/partof_BP3D_4.0_obj_99` 包含 1,258 个独立 OBJ 部件。应用会读取 `model-catalog.json` 中由 OBJ 文件头生成的 FJ 编号、英文名称和毫米范围，只有选中的部件才会加载到浏览器，因此不会在启动时一次性读取约 200 MB 几何数据。BodyParts3D 这批文件没有 MTL/纹理文件，界面使用科技风单色材质显示。

点击工作区顶部的“3D 解剖模型”后，可以按英文名称或 FJ 编号搜索，选中一个或多个结果并点击“添加选中部件”。场景列表可选择、显示/隐藏和移除部件；“拆分观察”会把选中独立部件从中心移开，“重置视角”会按当前场景重新居中。鼠标左键旋转视角、滚轮缩放、右键平移。

初次使用可先在模型库上方的“快速选择模块”选择胰腺、双肾、消化系统精选、主动脉主干或双侧股骨。点击“添加到当前场景”保留现有部件，或点击“清空后加载”用所选模块替换场景；模块由目录中真实存在的 FJ 编号组成，并会自动聚焦。建议先加载单个胰腺熟悉控件：点击“启用 3D 手势”，再用 V 字手势悬停选部件、单食指移动、握拳旋转、拇指与食指捏合缩放、竖起拇指切换到整体。放松手指即停止。拆分仍需单独点击“拆分观察”。

点击“导入 OBJ / GLB”可以导入本地模型；导入文件夹时，浏览器先索引 OBJ 文件头，搜索后再按需加载，适合整套 BodyParts3D 资源。Hyper3D 输出的 GLB 可从生成结果直接导入。进入“3D 解剖模型”后，绘画专属控件会隐藏。

## 3D 手控操作建议

启用 3D 手势后，无需再点移/转/缩切换按钮：V 字手势指向并停留约 0.55 秒可选部件；单食指移动，握拳旋转，拇指与食指捏合并上下移动来缩放；竖起拇指将目标切换为整体模型，之后继续使用单指、握拳或捏合操作整个场景。V 字选部件会自动返回部件目标。放松手指可停止操作，手离开画面会暂停并在重新检测后从当前点重新开始。

默认灵敏度为 0.65×、平滑为 65%。轻微抖动时把平滑提高到 75–85%；移动太快时把灵敏度降到 0.45–0.60×，拖动迟缓再小幅提高。选中的部件会显示青色包围框。“复位目标”恢复当前部件或整体的导入时变换；“复位全部”还原所有部件。“保存状态 / 恢复保存”在当前浏览器中保存并恢复当前部件组合的变换、显隐和相机视角。鼠标部件列表选择、轨道操作和变换手柄仍可作为备用；启用手势时移/转/缩与对象切换控件会隐藏。

单个 OBJ/GLB 内部如果只有一个网格，软件只能整体变换；BodyParts3D 目录中的每个 OBJ 已经是独立部件，所以可逐件拆分观察。Hyper3D 生成的 GLB 如果只有一个场景节点，也会作为一个整体部件导入；要实现器官级拆分，需要在建模软件中先分离网格后再导出多个 GLB/OBJ。

## 发布 / 打包

交付时保留 `index.html`、`styles.css`、`app.js`、`image-workflow.js`、`image-edit-service.mjs`、`server.mjs`、`package.json`、`vendor/`、`model-catalog.json` 和模型资源目录；不要把 `.env` 或 API Key 放进压缩包。Windows 用户可直接双击 `start-air-drawing.bat`，其他平台运行 `npm start`。发布前应在目标机器运行 `npm run check`，并用 Chrome/Edge 验证摄像头权限、WebGL、图像编辑、Hyper3D 任务状态和 GLB 导入。

`model-catalog.json` 可在资源目录更新后用 Node.js 重新生成：

```bash
node scripts/build_model_catalog.mjs
```
